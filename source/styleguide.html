Guia de Estilo

Referência visual interna — DrillPush Design System

Esta página documenta os elementos tipográficos e de interface usados em todo o site. Use-a como referência ao criar ou revisar páginas.

Toda página de conteúdo segue a estrutura: h1.page-title → h2.section-title → p.lead → conteúdo. Consulte a escala tipográfica e os exemplos abaixo antes de editar qualquer página.

Escala tipográfica

h1.page-title — Título da Página

h2.section-title — Subtítulo / Tagline imediatamente após o h1

h2.section-title — Seção de conteúdo

h3.subsection-title — Subseção

p.lead — Parágrafo de abertura. Ligeiramente maior que o texto corrido, usado uma vez por bloco de conteúdo principal para introduzir o tema com clareza.

p — Texto corrido padrão. Usado em descrições, explicações e parágrafos de suporte. Cor #273B46, tamanho 1rem, line-height 1.65.

h1.page-title → 2rem | fw-700 | #F6A728 (laranja) | borda inferior h2.section-title → 1.375rem | fw-600 | #273B46 (azul escuro) h3.subsection-title → 1.125rem | fw-600 | #273B46 p.lead → 1.0625rem | fw-400 | #273B46 | line-height 1.75 p → 1rem | fw-400 | #273B46 | line-height 1.65
Estrutura padrão de uma página de conteúdo

Título da Página

Subtítulo ou tagline que descreve o escopo da página

Parágrafo de abertura com a proposta de valor da página. Deve ser conciso, direto e responder à pergunta: o que o usuário vai encontrar aqui?

Parágrafo de suporte com detalhes adicionais. Pode haver múltiplos parágrafos seguidos. Use negrito para destacar termos técnicos ou conceitos-chave relevantes.

Segunda Seção

Introdução à segunda seção, se necessária.

Subseção com lista de itens:

  • Item de lista com descrição clara e objetiva;
  • Cada item termina com ponto e vírgula, exceto o último;
  • Use negrito para destacar o nome do item ou tecnologia;
  • Último item termina com ponto final.

Listas

ul.content-list — Lista de itens

  • Item com destaque — descrição complementar do item;
  • Segundo item — cada item começa com o nome em negrito seguido de traço e descrição;
  • Item simples sem negrito, quando o nome não precisa de destaque;
  • Último item termina com ponto final.

Regras de uso
  • h1.page-title — exatamente um por página. Título em laranja (#F6A728) com borda inferior.
  • h2.section-title — imediatamente após o h1 como subtítulo/tagline; depois usado para separar seções principais.
  • h3.subsection-title — subseções dentro de uma seção. Nunca pule níveis (h1 → h3 sem h2).
  • p.lead — um por bloco de conteúdo, logo após o h2 subtítulo. Não usar para texto corrido comum.
  • ul.content-list — toda lista de itens. Nunca usar <ul> sem essa classe.
  • table.product-table — toda tabela técnica. Nunca usar inline styles em tabelas.
  • Inline styles — proibidos. Toda estilização via classes CSS em style.css.
  • Fonte global — Montserrat (já definida em body). Nunca declarar font-family em elementos individuais.
